# Guía rápida de Git

Página web sencilla con los comandos de Git más usados, organizados por categoría, con buscador y botón para copiar cada comando.

## Contenido

- `index.html`: la guía interactiva (sin dependencias, funciona offline).
- `README.md`: documentación del proyecto.

## Cómo usarlo

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador.
3. Usa el buscador para filtrar comandos y pulsa **Copiar** para llevártelos al portapapeles.

## Subir este proyecto a GitHub

```bash
git init
git add .
git commit -m "Primer commit: guía rápida de Git"
git branch -M main
git remote add origin https://github.com/tu-usuario/tu-repositorio.git
git push -u origin main
```

## Flujo de trabajo básico con Git

1. `git status` para ver qué cambió.
2. `git add .` para preparar los cambios.
3. `git commit -m "mensaje"` para guardarlos.
4. `git push` para subirlos al remoto.
